# Tests this module's CI does not run, and why.
#
# tools/testreport reads this file. A test that skips in CI without appearing
# here fails the job: almost every tmux-driven test in this suite skips itself
# when tmux is missing rather than failing, so a job that only checked the
# exit code would be just as green with four tests run as with sixteen
# hundred. Naming the exceptions is what makes the green mean something.
#
# One entry per line: <package> <TestName>, '#' starts a comment. A name
# ending in '?' may skip rather than must -- for skips that depend on the
# host rather than on a switch -- and is the only kind that is allowed not to
# skip. Everything else is expected on every run, and an entry whose test has
# started running again fails the job too, so this file cannot quietly drift
# out of date.
